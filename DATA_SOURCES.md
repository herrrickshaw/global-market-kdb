# DATA_SOURCES

This repository tracks exactly one data file and derives everything else locally.

## 1. data/sample/ohlcv.csv (tracked)
- Publisher: this repository (generated by python/make_sample.py, fixed seed).
- Licence: MIT (same as code). Not market data; every number is synthetic.
- Fields: date, mkt (always SYN), sym (S001..S120), open, high, low, close, volume.
- Coverage: 120 names, 2018-01-01..2022-12-30 business days, 142,483 rows.
- Designed defects: missing rows, late listings/delistings, zero-volume days (1,483 rows), unadjusted jumps, high==close ties (14,074 rows).
- Refresh: never; regenerate with `python python/make_sample.py`.

## 2. data/local/*.csv, db/, out/ (NOT tracked, gitignored)
- Publisher: third parties via the sibling warehouse `herrrickshaw/global-market-data`: daily bars from Yahoo Finance with Stooq fallback (US, EU, JP, KR) and NSE/BSE bhavcopy (India). Terms of those providers apply; the bars are NOT redistributed here.
- Licence: provider terms (restrictive for redistribution). Do not commit.
- Fields: date, mkt, sym, open, high, low, close, volume (float64).
- Coverage used in published numbers: US + IN, 200 most-liquid names each, 2016-06..2022-12.
- Collection: `python/extract_sample.py` reads `~/.cache/market-warehouse/ohlcv/<MKT>/year=YYYY.parquet`.
- Caveats: unadjusted raw closes in India (corporate-action file optional, see `.ext.adjust`); survivorship per upstream warehouse; Corwin-Schultz spread overstates for liquid large caps.

## 3. Optional inputs for extras (local only)
- fundamentals_history/IN_screener_only_backup.parquet: India annual net income/shares from screener.in (account-based, terms restrict redistribution).
- adjustment_factors.parquet: split/bonus events derived by the warehouse.

## 4. Published results
README tables contain aggregate statistics (IC, t, spread bps) computed from section 2. They are derived results, not redistributed series.

## 5. Methods credited
Newey-West (1987), Benjamini-Hochberg (1995), Fama-MacBeth (1973), Harvey-Liu-Zhu (2016), Bailey-Lopez de Prado Deflated Sharpe (2014), Corwin-Schultz (2012), Lou-Polk-Skouras (2019), Acklam normal-quantile approximation. References only; no text copied.
